# Variant 008: Service Directory & Citizen Hub (008-service-directory)

## Design Stance
- **Principle:** Clean, modern digital public service portal (Gov.uk / Linear inspired design system).
- **Target Users:** Community members wanting to access formal community services without friction: applying for membership, tracking application status, booking community halls for family feasts (भोज / विवाह), applying for scholarships, or seeking emergency medical welfare grants.
- **Layout Axis:** Structured 2-column service catalog (sidebar category filters + 2-column service cards with clear requirement modals and tracking input).

## Key Choices
- **Application Tracking Box:** Immediate status lookup using application number or citizen registration number.
- **Categorized Service Cards:** Clear metadata per service (eligibility, fees, processing time, required documents).
- **Interactive Requirement Modal:** Provides transparent instructions before members start lengthy forms.
- **Strict Grayscale Tone:** Utilitarian, reliable, high trust.

## Trade-offs
- **Strong at:** Procedural clarity, digital governance, reducing manual office footfall.
- **Weak at:** Emotional/cultural celebration compared to Variant 007.

## Best For
A modern community administration that wants to digitize services, increase operational transparency, and provide self-serve convenience for all 24 Ilakas.
