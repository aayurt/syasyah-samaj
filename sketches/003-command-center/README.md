## Variant: Command Center

### Design stance
A dark, keyboard-first control panel — high-contrast crimson on slate, pill-style status, kbd hints, and minimal chrome so power users can fly through entry without touching the mouse.

### Key choices
- Layout: single column, full-bleed dark canvas, pill balance strip at top of step 2
- Typography: Inter UI + JetBrains Mono for numbers
- Color: crimson primary on deep slate, rose/emerald status
- Interaction: keyboard navigation hints (↑↓→Enter, A to add line), kbd badges on buttons, pill status shows balanced/unbalanced

### Trade-offs
- Strong at: speed, keyboard power users, status-at-a-glance
- Weak at: visual warmth, accessibility for low-vision users, non-technical staff

### Best for
- Power users, high-volume entry, keyboard-driven workflows
