## Variant: Calm Editorial

### Design stance
A guided, card-based wizard that feels approachable and unhurried — soft shadows, rounded cards, clear progress, and step-by-step disclosure so nothing feels overwhelming.

### Key choices
- Layout: single-column type list on step 1, centered cards on step 2; progress bar at top
- Typography: Inter, softer weights, sentence-case labels
- Color: crimson accent on white/slate-50, emerald balance states
- Interaction: type cards select with a soft fill, progress bar fills across steps, stat card shows live balance

### Trade-offs
- Strong at: clarity, first-time users, guided onboarding
- Weak at: entry speed (more clicks, more whitespace), power users

### Best for
- Occasional users, new bookkeepers, non-accountant staff entering vouchers infrequently
