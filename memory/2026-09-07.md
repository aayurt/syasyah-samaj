# 2026-09-07

## India-payroll replication (frappe/india-payroll) — SHIPPED

Continued the Nepal billing SPA (Payload + Vite + React). Built a **separate
Payroll system** switchable from Accounting, replicating frappe/india-payroll.

### Statutory engine (pure, jest-tested)
- `src/utilities/indiaPayroll.ts` — port of frappe/india-payroll:
  - **EPF**: S.O. 5109(E) ceiling ₹15,000→₹25,000 from 2026-09-17, day-weighted
    straddle, EPFO half-up rounding, post-2014 EPS rule (no pension above ceiling).
  - **ESI**: 0.75%/3.25%, ₹21,000 ceiling (₹25,000 PwD), coverage judged on cycle wage.
  - **Professional Tax**: 16-state slabs + revisions (Odisha repeal 2026-04-01,
    West Bengal 2026-10-01), Feb-₹300 rule, half-yearly/yearly cumulative,
    Maharashtra women's exemption.
  - **LWF**: 16-state amounts + deduction-month frequencies (monthly / Jun+Dec / Dec).
  - **Income tax/TDS**: new+old regime slabs FY25-26, std deduction, 87A rebate,
    surcharge + marginal relief, 4% cess.
- `src/utilities/payrollStatutory.ts` — wiring: per-line deductions (EPF/VPF/ESI/
  PT/LWF/TDS) + run-level employer contributions; `ptPriorPeriods` for periodic PT.

### Backend
- `globals/PayrollSettings.ts`: statute toggles (default OFF), registration numbers,
  default employment state, payable-account mappings (fallback Accrued Payables).
- `collections/Employees`: +employmentState, uan, esicNumber, gender, taxRegime,
  epfApplicable, lwfExempt, vpfAmount.
- `collections/PayrollRuns`: lines[].statutory snapshot + employerContributions[]
  + statutoryExpenseAccount. generate applies statutes; post accrues employer
  contributions (Dr statutory expense / Cr payables).

### SPA (separate Payroll system)
- `App.tsx`: `payrollNavGroups` on /payroll routes + Accounting⇄Payroll header
  switcher. Routes: /payroll, /payroll/employees, /payroll/registers, /payroll/settings.
- `pages/PayrollRegisters.tsx`: PF/ESIC/PT/LWF registers from run snapshots + CSV export.
- `pages/PayrollSettingsPage.tsx`: toggles + registration + account mappings.
- i18n en/ne + breadcrumbs for the new nav.
